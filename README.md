# Simulador de Planificación de CPU - FCFS

## Proyecto Final - Sistemas Operativos
Este proyecto consiste en el desarrollo de un simulador interactivo del algoritmo de planificación FCFS (First Come, First Served), implementado en Python utilizando Tkinter para la interfaz gráfica.
El sistema permite representar visualmente la administración de procesos dentro de un sistema operativo, mostrando el comportamiento de la CPU, la cola de procesos y los tiempos de ejecución.

# Funcionalidades
* Registro dinámico de procesos.
* Simulación del algoritmo FCFS.
* Visualización de procesos en cola.
* Ejecución paso a paso.
* Cálculo de tiempos de espera y retorno.
* Interfaz gráfica interactiva.
